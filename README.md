# People Search Engine NL

Een eenvoudige Nederlandstalige startpagina om openbare nieuwsberichten en professionele/publieke vermeldingen te vinden.

## Gebruik
Open `index.html` in een browser. Vul een voor- en achternaam in en eventueel een publieke context, zoals een sportclub, beroep, evenement of plaats van publieke activiteit. Kies daarna een zoeklink.

## Privacy en grenzen
- De app opent zoekopdrachten bij externe zoekmachines; hij scrapt of kopieert geen websites.
- Er worden geen zoekopdrachten of profielen opgeslagen.
- Niet bedoeld voor het opsporen van privépersonen.
- Geen verzameling van woonadressen, telefoonnummers, privé-e-mailadressen, familiegegevens of privéfoto's.
- Controleer bronnen en context zelf; naamgenoten kunnen voorkomen.

## Publiceren
Zet GitHub Pages aan via **Settings → Pages → Deploy from a branch → main → /(root)**. Na publicatie verschijnt de website op de GitHub Pages-URL die GitHub toont.
